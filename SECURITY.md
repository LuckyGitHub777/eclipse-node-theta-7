# Security Policy

## Supported version

Security updates target the latest release.

## Reporting

Use GitHub’s private vulnerability reporting feature when available. Do not include secrets, sensitive reflection content, or personal information in public issues.

## Security posture

The application is static and has no backend, account system, analytics, remote script, or data-upload path. Reflections are stored unencrypted in the active browser profile. Users should not enter confidential or sensitive information.
